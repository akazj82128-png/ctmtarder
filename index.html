Android APK 與 iOS PWA 安裝指南

🍎 iOS (iPhone / iPad) 直接安裝成桌面 APP (PWA)
  1. 使用 iPhone 的 Safari 瀏覽器開啟你的部署網址（如 Netlify 網址）。
  2. 點擊底部中間的「分享」按鈕 (方框向上箭頭圖示)。
  3. 往下滑動選單，點選「加入主畫面」(Add to Home Screen)。
  4. 點擊右上角「新增」，桌面即會出現黑橘配色的 CTM 交易巨獸 原生全螢幕 APP（無網址列、支援離線運作）！
🤖 Android 安裝 APK 或 PWA 雙方案

方案 A（免簽名秒裝 PWA）：用 Android Chrome 開啟網址，點擊右上角選單「安裝應用程式 (Install App)」，或點擊下方按鈕直接觸發安裝：

方案 B（生成獨立 `.apk` 安裝檔）：隨附提供的完整專案壓縮包 (ctm_trading_journal_apk_pwa_bundle.zip) 已內建標準 manifest.json、sw.js 與 capacitor.config.json：

  • 最快免寫程式生成 APK (PWABuilder)：將壓縮包內的 www 資料夾拖曳上傳至 Netlify 部署後，把網址貼到 pwabuilder.com 即可一鍵打包下載 Android .apk 安裝檔！
  • 本機 Capacitor 編譯 APK：解壓縮後執行 npm install && npx cap add android && npx cap open android 即可由 Android Studio 匯出簽名 APK。
